# WhatsApp Finance and File Agent

Node.js WhatsApp finance agent using Baileys, any [OI]-compatible AI provider, a persistent SQLite ledger, and a private file workspace reserved for the planned web panel. Any direct WhatsApp message can use the finance agent. Clear income and expense requests are recorded immediately, including multiple items in one message; natural-language export requests send a CSV directly. Users can correct or void transactions by ID without a save-confirmation keyword.

## Run Locally

Requires Node.js 22.13+ on the 22.x line, 24.x, or 26+. Node 23 and 25 are unsupported by the current dependency tree. Copy `.env.example` to `.env`, fill in the values, then run:

```sh
npm test
npm start
```

The app loads `.env` automatically. Environment variables already set by Pterodactyl take precedence. Any direct WhatsApp DM can use the agent, so anyone who can message the bot may consume your provider quota. Scan the Baileys QR from WhatsApp → Linked Devices. Baileys credentials are stored under `DATA_DIR/baileys-auth`; keep this directory persistent and secret.

## WhatsApp

Every text message is sent to the AI agent; there are no required command words or exact message formats. Clear transactions are saved immediately, including multiple separate items in one message, without an approval or verification reply. The agent can also prepare professional multi-sheet Excel reports, export CSV, find or correct a transaction, manage saved preferences, and handle older pending drafts from natural-language requests. While working, it edits one WhatsApp progress timeline with sanitized action labels; its final answer is sent as a second message. The timeline never exposes internal reasoning. Transaction IDs are useful when identifying a specific record to correct or void, but command keywords are not required.

WhatsApp attachments are stored in the sender's private workspace. The AI manages files through a per-user filesystem MCP bridge; no file keywords or chat command handlers are used. File deletion moves items directly to reversible Trash, and Office edits made through the built-in tools are saved as copies. Excel MCP Server (`@negokaz/excel-mcp-server` 0.12.0) adds formula-aware Excel tools for `.xlsx`, `.xlsm`, `.xltx`, and `.xltm`; its write tools edit the target workbook directly. Uploaded workbooks can be selected by private `file_id`, or an explicitly named absolute path inside the server container can be used. Excel MCP uses local files only and does not connect to OneDrive or require Microsoft authentication.

Set `PANEL_PASSWORD` in the Pterodactyl egg environment to enable password login; the value is never shipped to browser code. Transactions are stored as balanced postings in `data/finance.sqlite` as soon as a clear record request is processed. An expense reduces `Assets:Cash` and increases `Expenses:<category>`; income increases cash and offsets `Income:<category>`. Duplicate Baileys message IDs are idempotent. Corrections keep before/after revision records; voided transactions leave active reports and exports while their audit history remains. CSV export escapes spreadsheet formula prefixes.

## Pterodactyl

Set `PANEL_OWNER_NUMBER` to the owner's WhatsApp number using digits only; its private workspace and finance records power the panel after login. Microsoft login and OneDrive access are not used. Excel MCP runs as a child process under the same OS account as the agent and can access any file readable or writable by that account inside the container; its direct write tools modify the selected workbook. Because any WhatsApp direct message can use the agent, protect the bot number and do not mount secrets or unrelated data into the container unless you accept that exposure. The web panel stores only a random session token in the current tab; configure the requested password as `PANEL_PASSWORD` in the Pterodactyl egg variables.

If `SERVER_IP` is missing or wildcard, startup makes a short public-IP lookup and prints a dashboard URL with the allocated port; behind NAT or a reverse proxy, that observed address may differ from the browser-facing allocation. Leave `AI_SEARCH_URL` empty on providers without a search endpoint. Open `/dashboard` at the server's allocated address for the live panel. Set `DATA_DIR` to a persistent server directory mounted outside any ephemeral container layer; it contains Baileys auth, finance database, file index, uploads, and generated files. `EXCEL_MCP_PAGING_CELLS_LIMIT` optionally controls the maximum cells read per Excel MCP page (default 4000). Microsoft Device Code login is not used. The agent connects directly through Baileys; no Meta webhook, phone-number ID, or Cloud API token is used. On first start, scan the QR from the Pterodactyl console using the WhatsApp account that will run the bot.

`AI_API_KEY` must be available through `.env` or the egg; secrets cannot be generated by the app. All direct messages can use the agent and consume your provider quota. `DATA_DIR` should be persistent. Other settings have defaults in `.env.example`. `AI_MODEL` accepts any model id your provider exposes. Legacy `XKIRO_*` variables still load for backwards compatibility.

## Backup

The authenticated panel's **Cloud Backup** page creates a ZIP for direct download; it does not upload data to a third-party cloud. Select AI memory/conversations, owner-scoped finance and audit data, the File Explorer workspace (including Trash and file revisions), non-secret skills/runtime settings, and optionally the WhatsApp session. Archives are kept under `DATA_DIR/backups`, with only the five newest retained. Keep `DATA_DIR` on persistent Pterodactyl storage. API keys, panel passwords, `.env`, other owners' data, and application source are excluded. WhatsApp session credentials are sensitive, are excluded unless selected, and the ZIP is not encrypted.

The same page accepts a generated ZIP by file picker or drag-and-drop. Import restores only the selected components and replaces that owner's current data for those components; it rejects archives for another owner. Before applying changes, the server creates a safety ZIP of the current selected data. If a restore step fails, it attempts to roll back from that archive. Runtime environment values remain controlled by Pterodactyl; importing WhatsApp credentials requires a server restart to take effect.

## Current Limits

Each WhatsApp number has one continuous timeline; there is no chat alias or new-session command. SQLite stores the conversation across restarts, the latest 12 messages are supplied as context, and older messages can be recalled with a parameterized SQLite `LIKE` search that does not require FTS5. Hermes-style `user` and `memory` notes are injected each turn, with 1,375 and 2,200 character limits. This MVP does not yet import bank feeds, reconcile statements, manage budgets, create automatic backups, or sync directly to a cloud spreadsheet; Google Sheets can open/import the CSV export. File deletion is reversible through the private workspace Trash; restore it through the file function tool. Configure and test encrypted backups of `DATA_DIR` before using this as the only record of real finances.

Conversation context, memory, prompts, and tool results are sent to the configured AI provider. If the agent searches prior messages or inspects a file, relevant content is included in that request. Web search has a separate quota and may incur charges; private details are not intentionally sent to web search. Memory rejects obvious credentials, exact amounts, account identifiers, and common prompt-injection patterns, but review what the agent remembers with `MEMORI`. Baileys is an unofficial WhatsApp Web client; usage may violate WhatsApp policies or lead to device logout/account restrictions. One global FIFO queue processes all senders; outbound messages are separated by at least 5 seconds, with no extra wait if work already took longer. This pacing limit does not guarantee freedom from WhatsApp restrictions. Do not commit `.env`, `DATA_DIR`, or backups.
